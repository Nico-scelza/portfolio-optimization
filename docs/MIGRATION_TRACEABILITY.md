# Architecture Revision & Legacy Notebook Traceability

This document tracks the superseding functional and quantitative revision (`v0.2.0`, branch `feat/stateless-multiasset-portfolio`) built on top of the initial faithful notebook migration (`v0.1.0`, `main` @ `408b612cfb50412b50474ee01f2d6edebac4bf50`).

## Summary of Superseding Changes (v0.1.0 -> v0.2.0)

| Area | Legacy v0.1.0 State (Colab Migration) | Revised v0.2.0 Implementation |
| :--- | :--- | :--- |
| **State & Persistence** | Process-wide mutable globals in `state.py` | `state.py` deleted; 100% stateless request-in (`PortfolioAnalysisConfig`) -> result-out (`AnalysisResult`) architecture with JSON-safe `.to_dict()`. |
| **Country / Sovereign Risk** | `country_risk.py` (Ámbito, Rava, ETF vol ratios), `pais_riesgo` spread subtraction | `country_risk.py` deleted; all sovereign/country-risk spreads removed; geographic metadata preserved solely for currency/market/calendar; sovereign bonds remain eligible fixed-income instruments. |
| **Machine Learning** | `ml.py` (`DataIngestor`, `PortfolioProcessor`, `PortfolioPredictor`, XGBoost, `TimeSeriesSplit`, `predicciones_ml`, `predicciones_5y`) | `ml.py` deleted; `xgboost` and `tqdm` removed from dependencies; DCF is the sole equity fundamental valuation input into Black-Litterman. |
| **Dead Code & Unused Keys** | 10 `_build_*` stubs returning `Path`, `_process_macro`, `_fetch_alpha_vantage_financials`, `GEMINI_API_KEY`, `ALPHA_VANTAGE_API_KEYS`, `GOOGLE_NEWS_RSS_URL`, `_analyze_portfolio_cell10` | All deleted; TLS verification (`verify=True`) restored everywhere; only active optional server credential `FRED_API_KEY` remains. |
| **Pandas 3.x & FX** | `fillna(method='ffill').fillna(method='bfill')`, `SettingWithCopyWarning`, silent fallback returning raw LCY prices as USD | Pandas 3.x native (`pandas 3.1.1` verified); ascending sort, explicit duplicate-date policy, subunit-aware (`GBp`/`GBX`), causal `merge_asof(..., direction='backward', tolerance=...)`, explicit `FXConversionError` on missing/stale FX. |
| **Expected Returns** | Raw multi-year upside plugged in as annual return; presence of DCF disabled BL completely | Geometric annualization `(V_T/P_0)^(1/T)-1` (plus present-value convergence and dated-cashflow IRR); Black-Litterman active for full multi-asset universe using excess returns over `rf`, Idzorek $\Omega$, and non-singular Woodbury posterior. |
| **Fixed Income & IOL** | Not supported | Manual contractual schedules (`fixed_income.py`) with clean/dirty price conventions, amortization tracking, multi-root-checked XIRR/YTM, duration/WAL; public IOL Bonos/ONs BeautifulSoup parser (`iol.py`) with fixed Argentine number parsing and `D -> C -> ARS/MEP (AL30/AL30D)` resolution. |
| **Weekly Risk & VIX Regime** | Daily resampled `.ffill()` returns with `fillna(0)`, fixed 70/30 blend with `1.5x` fallback, and global scalar `forward_looking_cov_adjustment` multiplier | Weekly `W-FRI` returns without artificial zeros or multi-week returns across gaps; annualized ONCE ($\times 52$); dynamic $\Sigma(p) = (1-p)\Sigma_{\text{calm}} + p\Sigma_{\text{crisis}}$ driven by editable VIX schedule (default `<15: 0.15`, `15..20: linear->0.35`, `20..30: 0.35`, `>30: 0.60`); strict sample-size and missing-VIX guards; optional EWMA. |
| **Constraints & Optimizers** | Hardcoded `(0.05, 0.20)` bounds (infeasible for $n<5$ or $n>20$) with silent `1/n` fallback; Sharpe, MinVar, CVaR only | Neutral configurable asset/class/HHI/sector bounds with exact LP feasibility validation and zero silent `1/n` fallback; added Risk Parity (`erc`) and Hierarchical Risk Parity (`hrp`, zero $\Sigma^{-1}$, pure vs constrained-adjusted diagnostics); Rockafellar-Uryasev LP for `min_cvar`. |
| **Rebalancing** | Single-broker cost-free weight delta in `_calcular_rebalanceo` | Multi-broker fractional rebalancing (`rebalancing.py`) separating instrument risk identity from broker positions, supporting fixed/percentage/combined/min fees, FX conversion, optional spread, editable dual thresholds (`min_weight_diff`, `min_notional_usd`), cash reconciliation, and hard-limit conflict checks. |
| **Unified Entrypoints** | `ejecutar_analisis_completo` diverged from `analyze_portfolio` | `ejecutar_analisis_completo`, `run_portfolio_analysis`, and `analyze_portfolio` share the exact same validated `PortfolioAnalysisConfig` -> `AnalysisResult` pipeline. |
