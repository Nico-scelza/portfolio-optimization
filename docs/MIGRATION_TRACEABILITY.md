## Documented Pre-Existing Limitations (Preserved Faithfully, Not Altered)

1. **Process-wide mutable state (`state.py`)**: Not isolated per user/session or thread-safe; a future multi-user web backend must encapsulate state per request/session in a later phase.
2. **TLS verification disabled (`verify=False`)**: `DataIngestor._fetch_alpha_vantage_financials` (Cell 15) calls `self.session.get(..., verify=False)` and `configure_runtime` / `_download_prices` disable `urllib3` `InsecureRequestWarning`. Preserved verbatim per migration rules; recommended for remediation in a future security pass.
3. **Country risk forwarding gap in `ejecutar_analisis_completo` (Cell 19)**: `ejecutar_analisis_completo` constructs `assets` dicts without forwarding `pais_riesgo` / `pais` from `activos_dict`, unlike direct calls to `analyze_portfolio`. Preserved verbatim.
4. **Unused/dead paths preserved**: `predicciones_ml` (1Q short-term) is never populated by `ejecutar_analisis_completo`; `DataIngestor._fetch_alpha_vantage_financials` is not called by `ingest_all()`; `PortfolioProcessor._process_macro` (monkey-patched in Cell 17) is not called by `process_all()`; the 10 `_build_*` chart functions in Cell 10 return `output_path` without writing image files; `GEMINI_API_KEY` is defined in Cell 01 and unused elsewhere.
5. **Pandas deprecation in `DataIngestor._convert_to_usd` (Cell 15)**: Uses `fillna(method='ffill').fillna(method='bfill')`, which fails on pandas 3.x (removed after deprecation in pandas 2.1) and triggers the `except` fallback returning original prices.
6. **Non-determinism**: `_simulate_portfolios` (Cell 10) and `generar_frontera_eficiente` (Cell 22) use unseeded NumPy RNG (`np.random.random` / `np.random.dirichlet`).
7. **Fixed optimizer bounds `(0.05, 0.20)`**: Optimization problems in Cells 09, 10, and 12 are infeasible when `n_assets < 5` or `n_assets > 20`, triggering the equal-weight fallback (`1/n_assets`).
8. **Descending sort before `TimeSeriesSplit` (Cell 16)**: `PortfolioProcessor` returns DataFrames sorted descending by `date`, and `_train_xgb_robust` splits without re-sorting ascending. Preserved verbatim.
9. **Interactive UI parity**: `ipywidgets` interactive widgets (`crear_interfaz_portfolio`, `ejecutar_interfaz_analisis`, `crear_interfaz_proyecciones_ml`, `mostrar_rebalanceo`) were statically verified but not executed inside a live Jupyter kernel in this migration pass.
